# Local ancestry examples

Software and algorithm owner: **Yuzhuo Ma <yuzhuoma@amss.ac.cn>**. Every example here is generated by this project's simulation scripts. The native SPAGxE executable performs decoding and association; R is optional for independent numerical reference calculations.

The canonical method name is `SPAGxEmix_local`; `SPAGxElocal` remains an alias. Run commands from `cpp/`, create `results/local`, and put each command on one line. On Windows the executable is `build\bin\SPAGxE.exe`.

## Paired G/H text

```sh
build/bin/SPAGxE --method SPAGxEmix_local --local-manifest examples/local/cohort.local.tsv --pheno examples/local/samples.pheno --pheno-name Quantitative,Binary,Ordinal,Time:Event --covar-name X,E --envir-name E --regression-model auto --maf 0 --mac 0 --geno 1 --threads 4 --out results/local/native
```

`samples.pheno` contains 160 simulated people, four raw trait families, illustrative residual columns, a masked residual, covariate X and environments E/Eshift. `cohort.local.tsv` joins the two-ancestry G/H tables. `three_ancestry/cohort.local.tsv` supplies three ancestries with the same sample IDs. The generator `tests/make_local_fixtures.py` uses seed 20261024 for these text examples.

Cases include common/rare markers, strong genetic main effects, ancestry AF above 0.5, missing G/H, structural H=0 and fractional G. Keep/remove and extract/exclude lists illustrate filters. Permissive example QC values deliberately expose edge cases; choose appropriate thresholds for real data.

## Packed hardcall counts

`binary_demo/` is an independently simulated count-container example: 450 people, 18 markers, two ancestries, seed 20261025. `SIMULATION.json` records its simulation settings. Its matching paired G/H files provide an independent input representation for numerical comparisons.

```sh
build/bin/SPAGxE --method SPAGxEmix_local --local-prefix examples/local/binary_demo/local --pheno examples/local/binary_demo/samples.pheno --resid-name R --envir-name E --maf 0 --mac 0 --geno 1 --out results/local/binary
```

The prefix selects the matching `.localbed/.localbim/.localfam` files. These encode local ancestry G/H counts, not ordinary PLINK BED. `--local-binary` is a compatible alias for `--local-prefix`.

## Known-H BGEN probabilities

`bgen_demo/` is independently simulated with seed 20261025. It contains three-ancestry Layout 2 BGEN examples across raw/zlib/zstd compression and 1, 8, 16, 24 and 32 probability bits. Each set includes a three-column `.localbgen.tsv` manifest and a four-column `.local.tsv` manifest of expected G/H text. G is calculated independently from stored quantized probabilities, not from C++ decoder output.

Samples have H=0/1/2, missing genotype posteriors, point calls, fractional means, uncertain integer means and ancestry frequencies above 0.5. Files deliberately use different IID orders to verify alignment. `two_ancestry/` adds a two-ancestry example with seed 20261026. Generate these with `tests/make_local_bgen_fixtures.py`.

```sh
build/bin/SPAGxE --method SPAGxEmix_local --local-bgen-manifest examples/local/bgen_demo/bits16_zlib.localbgen.tsv --pheno examples/local/samples.pheno --pheno-name Quantitative,Binary,Ordinal,Time:Event --covar-name X,E --envir-name E --regression-model auto --maf 0 --mac 0 --geno 1 --threads 4 --out results/local/bgen
```

For residual mode, use `--pheno examples/local/bgen_demo/samples.pheno --resid-name R --envir-name E` instead of the raw-phenotype/covariate options. The same three-column BGEN manifest is auto-detected by `--local-manifest`.

## Meaning, directions and verification

H is a known integer ancestry-copy count, not a continuous ancestry probability. Provide all ancestries with sum(H)=2. Unknown H excludes a person from every ancestry test at that marker. Missing G is H*q, except H=0 gives structural zero. Fractional G uses the conditional-binomial working model; reading posterior probabilities does not imply exact integration of imputation uncertainty.

REF-counted text is converted to ALT with H-G. BGEN probabilities intrinsically count the second listed allele: changing only its manifest counted direction does not swap its alleles. A genuine allele reversal exchanges both allele metadata and posterior categories. Inputs must have matching marker metadata across ancestries. Tests report the ancestry minor direction through `TESTED_ALLELE`/`MINOR_FLIPPED` and preserve original `ALT_FREQ`.

The release uses one complete conditional-binomial CGF with its normal/SPA threshold. No approximate-CGF profile is exposed. Agreement with the original R implementation is assessed only in stated comparable domains; input and numerical boundary fixes are tested separately. The examples do not establish local-ancestry relatedness correction or universal calibration.

```sh
python -B tests/verify_local.py build/bin/SPAGxE results/verify_local
python -B tests/verify_local_bgen.py build/bin/SPAGxE results/verify_local_bgen
```
