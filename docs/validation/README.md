Its 80 production source/header files are unchanged from the accepted
2026-10-28 numerical implementation. Current packaging and installation checks
were executed again; previous original-R, frozen-core and timing comparisons
are inherited evidence with an explicit source-hash condition.

- A normal local Git add with core.autocrlf=true was archived, extracted and
  built from scratch. Numerical units and all 17 regression suites passed.
- 64,960 current-to-accepted-partial comparison fields
  had maximum numeric difference 0.
  The separate full-CGF comparison records approximation differences and is
  not an equality requirement for the accelerated method.
- The new local preparation guide's four native commands passed. Packed and
  paired-text analyses produced identical association and CCT tables.
- The six source tutorials and extracted Windows bundle produced 45 identical
  non-log outputs. Version and bundle tutorials ran with only Windows system
  directories in PATH; R, Python and a compiler are not analysis dependencies.

## Complete feature-guide review

The [official user guide](../USER_GUIDE.md) has 33 executable groups covering
all 53 canonical CLI parameters. Its matching optional feature walkthrough
executes 38 native calls. The Windows and Bash source walkthroughs passed and
produced 85 byte-identical files. Format, conversion, residual-score reuse,
QC exclusion and CCT-weight assertions were also checked. These are teaching
and representation checks, not an additional calibration study.

This documentation update does not change any of the 80 production
source/header files, bundled dependencies or build options. The clean build,
17 regression suites and numerical comparisons above remain earlier accepted
evidence under those exact hashes; they were not rerun for a README change.

The inherited independent scalar-R references include actual partial
acceptance for base, plus, mix and local and full-law protection cases.

degeneracy and support boundaries. The three 1e-3 CGF diagnostics are not a
P-value error bound. Neither full nor partial SPA is exact enumeration.

complete candidate bundles on the target runners; its actual develop/main

checks are not remote execution. Universal tail calibration, every historical
